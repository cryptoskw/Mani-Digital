# Mani Digital GitHub Pages Package

This package is a static GitHub Pages version of Mani Digital.

## Deploy

1. Create a GitHub repository.
2. Upload all files and folders from this package into the repository root.
3. In GitHub, open Settings > Pages.
4. Deploy from the main branch and root folder.

The package uses relative links so it can run from a GitHub Pages project path such as /repository-name/.

## Notes

- No PHP, WordPress, SSI or server processing is required.
- The contact flow uses email, telephone and WhatsApp links.
- .nojekyll is included so GitHub Pages serves the _next asset directory.
- Canonicals and sitemap entries still point to https://manidigital.co.za so the GitHub version can act as a temporary mirror without splitting SEO signals.
